# Comparación
1. new + asignación posterior: visual y sencilla, pero requiere más líneas.
2. Constructor con parámetros: inicializa desde el comienzo y deja claros los datos requeridos.
3. Sobrecarga: permite varias formas de construcción, pero agrega complejidad.

Para principiantes, el constructor con parámetros suele ser claro cuando el objeto requiere datos desde el inicio.
